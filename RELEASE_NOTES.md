# Release Notes

Short release checklist for the change lifecycle rehearsal.

- [ ] Verify build passes on the default branch before cutting a release candidate
- [ ] Review the diff on the release PR and confirm checklist items are complete
- [ ] Update version number and changelog entry in RELEASE_NOTES.md
- [ ] Run the post-merge smoke test and confirm the default branch is green
- [ ] Tag the release and notify the release manager on the #releases channel
